# Каталог источников лотов: авто и спецтехника

> **Дата:** 27.10.2026.
> **Статус:** черновик. Состав групп и домены собраны через веб-поиск. Их нужно сверить с официальными списками, когда появится прямой доступ к сайтам: «Список торговых площадок» в ЕФРСБ и извещения на torgi.gov.ru.

Приоритет подключения:

- **P1** — нужно для MVP;
- **P2** — после запуска;
- **P3** — длинный хвост или по запросу.

---

## Главное

- **Почти все торги по банкротству и аресту стекаются в два госреестра.** Банкротные торги со всех площадок попадают в ЕФРСБ: площадки обязаны отправлять туда сообщения о ходе торгов. Арест, конфискат, приватизация и муниципальное имущество обязательно публикуются на torgi.gov.ru.
- **Сами площадки (ЭТП) нужны не для поиска лотов, а для деталей:** фото, документов, текущей цены, статусов. На топ-5 площадок приходится около 70% банкротных торгов, на топ-10 — около 81%.
- **Единого реестра нет только у залогов банков и у лизинговых стоков.** Их придётся подключать отдельно: партнёрствами, фидами или парсингом.

---

## Группа 1. Государственные реестры

Эти реестры собирают данные со всех площадок.

**ЕФРСБ** — bankrot.fedresurs.ru · **P1**
- Что там: все банкротные торги со всех ЭТП — объявления, сообщения площадок о ходе торгов, итоги, отчёты об оценке.
- Доступ: REST API (платный, нужен договор с АО «Интерфакс») или парсинг сайта. Сайт ограничивает частоту запросов: 429/451 уже при 8 параллельных.

**ГИС «Торги»** — torgi.gov.ru · **P1**
- Что там: арестованное имущество (ФССП → Росимущество), конфискат, приватизация, муниципальное имущество.
- Доступ: «Открытые данные» — бесплатно, без договора, можно использовать в коммерческих целях. Плюс неофициальный JSON API самого сайта.

**Маркетплейс Росимущества** — fiol.rosim.gov.ru (адрес по данным статьи, сверить) · **P2**
- Что там: арестованное имущество, в том числе продажи без торгов (на комиссионных началах).
- Доступ: парсинг.

**ФНС «Витрина имущества банкротов»** — маркетплейс на kartoteka.ru · **P2**
- Что там: имущество банкротов, у которых кредитор — ФНС; транспорт тоже есть. Сервис сам подтягивает данные из Росреестра, ГИБДД и ЕФРСБ.
- Доступ: парсинг.

**«Коммерсантъ»** (официальное издание для сведений о банкротстве) · не нужен
- Что там: то же, что в ЕФРСБ.

Арестованное имущество продаёт Росимущество: у него исключительное право на это. Продажу ведут его территориальные управления и привлечённые организаторы торгов на ЭТП.

## Группа 3. Арестованное, конфискованное, государственное и муниципальное имущество

Все извещения обязательно публикуются на **torgi.gov.ru**, поэтому основной источник здесь — ГИС «Торги» (**P1**). Сами площадки нужны для деталей (**P2**).

- **Сбербанк-АСТ** — sberbank-ast.ru: приватизация, аренда, продажа арестованного имущества.
- **РТС-тендер** — rts-tender.ru: имущественные торги.
- **Росэлторг (АО «ЕЭТП»)** — roseltorg.ru: продажа имущества.
- **ЭТП ГПБ** — etpgpb.ru: имущественные торги.
- **ТЭК-Торг** — tektorg.ru: продажа имущества.
- **РАД** — lot-online.ru: государственное и банковское имущество.
- **Фабрикант** — fabrikant.ru. Например, в Новосибирской области арестованное имущество продаёт здесь специализированная организация.
- **ВЭТП** — раздел «Продажа арестованного имущества»; тарифы утверждены 19.08.2025.
- **«эЛот», «Арестторг.рф»** — специализированные площадки для арестованного имущества; сайты нужно уточнить.

## Группа 7. Готовые фиды

Это поставщики уже собранных данных, а не первоисточники лотов.

**«Банкротный шпион»**
- Что дают: полную базу по API, обновление раз в сутки.
- Стоимость: 25 000 ₽/мес.

**«Гевея»**
- Что дают: доступ по API по агентскому договору.
- Стоимость: 6,22 ₽ за лот без фото, 17,30 ₽ — с фото и файлами.

**Посредники с API к ЕФРСБ** (api-assist, parser-api, checko, apiportal)
- Что дают: данные ЕФРСБ, в основном о должниках.
- Стоимость: разная.

**TBankrot, «Торги России», ScanLot**
- Публичного API у них не нашёл.

## Группа 8. Источники для проверки и оценки

Эти источники не дают лотов, они дополняют карточку.

- **ГИБДД** (ограничения, розыск, ДТП, история регистраций) — через API-агрегаторы: Apipoint (от 2 ₽), AvtoVinCod, API Assist, TRONK.
- **Реестр залогов ФНП** — через тех же агрегаторов.
- **ФССП** (исполнительные производства) — через тех же агрегаторов.
- **СЭП** (выписка из ЭПТС или ЭПСМ) — около 250 ₽ за выписку.
- **Гостехнадзор** — нужен для спецтехники; онлайн-проверка ограничена.
- **Авито, Авто.ру, Дром** (рыночная цена) — публичного API нет, нужен свой сбор данных и своя модель оценки.

## Что меняет реформа банкротства (253-ФЗ)

Закон подписан 26.07.2026.

- **Сроки:**
  - большая часть изменений вступает в силу **27.07.2027**;
  - отдельный режим для лотов дороже 1 млрд ₽ и новый порядок продажи долей — с **01.01.2028**;
  - ограничения для «малых» площадок — **с 2030 г.** Если у площадки меньше 1% сообщений о торгах в ЕФРСБ за год, она не сможет брать новые торги с начальной ценой выше 10% компенсационного фонда своей СРО.
- **Новый порядок торгов** (по обзорам, сверить с текстом закона): цена снижается до первого предложения, после чего начинает расти. Минимальная цена — не ниже 50% начальной на первых торгах и не ниже 25% на повторных.
- **Что это значит для нас:**
  1. рынок площадок, скорее всего, сократится, и со временем парсеров понадобится меньше;
  2. привычное «публичное предложение» изменится, поэтому модель данных о цене и уведомления должны поддерживать и старую, и новую схему;
  3. ЕФРСБ остаётся центральным источником.
